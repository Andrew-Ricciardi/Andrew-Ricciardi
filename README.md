**How I write things up**
Every finding gets the same shape, whether it turns into a CVE or nothing at all:
- what it is and where
- affected versions, and the first fixed version
- root cause, in plain words
- impact, stated honestly
- steps to reproduce, boring bits included
- disclosure timeline, and credit where it is due
